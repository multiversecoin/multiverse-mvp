## 🎤 Dicas para Apresentação

### Para o Pitch

1. **Seja conciso**: 3 minutos é rápido - vá direto ao ponto
2. **Foque no problema local**: Jurados valorizam impacto na comunidade
3. **Mostre, não diga**: A demonstração do app é mais poderosa que slides
4. **Use dados reais**: Mesmo que demonstrativos, apresente como métricas
5. **Conecte com o tema**: "Hack for Humanity" = impacto humano

### Durante a Demonstração

1. **Prepare o adiantado**: Abra o app antes de começar
2. **Destaque o fluxo completo**: Home → Explorar → Transação → Impacto
3. **Mencione a segurança**: Destaque os guardrails implementados
4. **Mostre a responsividade**: Se possível, demonstre em mobile
5. **Esteja preparado para perguntas**: Sobre blockchain, segurança, escalabilidade

### Respostas a Perguntas Prováveis

**"Por que Moema?"**
- "Moema é um laboratório ideal: compacto, denso, alta atividade comercial, easy para validar o modelo antes de expandir."

**"Como vai ser implementado o blockchain?"**
- "A arquitetura está preparada, mas fora do escopo inicial do MVP. Futuramente usaremos blockchain para rastreabilidade de transações e transparência do impacto."

**"Como garantem a segurança?"**
- "Implementamos guardrails abrangentes: sanitização de input, rate limiting, detecção de anomalias, tokens seguros, e auditoria completa. Documentação detalhada disponível."

**"Como vão conseguir adesão de comerciantes?"**
- "Modelo win-win: comerciantes aumentam vendas e recorrência, recebem dados de clientes, e participam do ecossistema de impacto. Começamos com pilotos e expandimos por network effect."

**"Qual o modelo de negócio?"**
- "49% das transações mantém o negócio sustentável: tecnologia, operação, escala. 51% vai para impacto social. Modelo transparente e alinhado com propósito."

## 📱 Preparação Técnica

### Para a Demonstração

1. **Teste o app localmente**: Abra `index.html` e verifique tudo funciona
2. **Prepare dados de demonstração**: Garanta que as transações funcionam
3. **Teste responsividade**: Se possível, teste em device móvel
4. **Backup**: Tenha o arquivo `index.html` disponível offline
5. **Screenshot gravação**: Grave a demonstração como backup

### Equipmento

- Laptop com o app aberto
- Cabo HDMI para projetor (se necessário)
- Backup em pen drive
- Versão mobile (se possível)
- Print do QR code do GitHub (para jurados)
