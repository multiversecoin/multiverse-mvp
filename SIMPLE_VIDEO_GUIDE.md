# 🎬 Guia Simples - Como Criar o Vídeo (Canva)

## 🚀 Opção Mais Rápida: Canva (Grátis)

### Passo 1: Acessar Canva
1. Acesse: https://www.canva.com
2. Crie uma conta gratuita
3. No buscador, digite: "Video Presentation" ou "Pitch Deck"

### Passo 2: Usar Template
1. Escolha um template de apresentação
2. Clique em "Use this template"
3. O template já terá transições automáticas

### Passo 3: Editar Slides (Use este conteúdo)

**Slide 1 - Título:**
- Título: "MULTIVERSE"
- Subtítulo: "Economia Digital Territorial"
- Logo: Cole o logo.jpg

**Slide 2 - Problema:**
- Título: "O Problema"
- Texto: "12M habitantes em São Paulo"
- Subtítulo: "Economia local fragmentada"

**Slide 3 - Solução:**
- Título: "A Solução"
- Texto: "MULTIVERSE"
- Subtítulo: "Plataforma de Economia Digital Territorial em Moema"

**Slide 4 - Como Funciona:**
- Título: "Como Funciona"
- Texto: "App mobile-first conecta pessoas, comércio, impacto e segurança"

**Slide 5 - Transação:**
- Título: "Transação com Impacto"
- Texto: "51% para projetos sociais locais"
- Subtítulo: "49% sustenta o negócio"

**Slide 6 - Inovação:**
- Título: "Inovação"
- Texto: "Guardrails de segurança + Blockchain-ready + Segurança territorial"

**Slide 7 - Impacto:**
- Título: "Impacto Social"
- Texto: "R$ 12.450 gerados em Moema"
- Subtítulo: "17 famílias impactadas"

**Slide 8 - Visão:**
- Título: "Visão de Futuro"
- Texto: "Moema → São Paulo → Brasil"

**Slide 9 - GitHub:**
- Título: "Código Disponível"
- Texto: "github.com/multiversecoin/multiverse-mvp"

**Slide 10 - Final:**
- Título: "Obrigado!"
- Subtítulo: "Hack for Humanity: São Paulo 2026"

### Passo 4: Configurar Tempo
1. Clique em cada slide
2. No painel direito, configure "Duration" para 6 segundos
3. Ou configure "Set timing for all slides" para 6s

### Passo 5: Adicionar Música
1. Vá em "Elements" → "Audio"
2. Escolha uma música gratuita
3. Ajuste o volume para baixo (20-30%)

### Passo 6: Exportar
1. Clique em "Share" → "Download"
2. Escolha "MP4 Video"
3. 1080p (HD)
4. Clique em "Download"

## 🎯 Opção Alternativa: PowerPoint

### Passo 1: Criar PPT
1. Abra PowerPoint
2. Crie nova apresentação
3. Use o conteúdo acima (10 slides)

### Passo 2: Adicionar Imagens
1. Insira o logo.jpg nos slides
2. Adicione screenshots do app
3. Use o conteúdo dos slides acima

### Passo 3: Configurar Transições
1. Vá em "Transitions"
2. Escolha transição suave (Fade)
3. Configure "After" para 6 segundos
4. Aplicar a todos os slides

### Passo 4: Exportar como Vídeo
1. File → Export → Create a Video
2. Escolha qualidade "HD (1080p)"
3. Clique em "Create Video"

## 🎤 Opção com Narração: Loom (Mais Fácil)

### Passo 1: Instalar Loom
1. Acesse: https://www.loom.com
2. Instale a extensão ou app
3. Crie conta gratuita

### Passo 2: Gravar
1. Abra o app Multiverse (index.html)
2. Abra a apresentação (presentation.html)
3. Inicie gravação no Loom
4. Fale seguindo o roteiro:
   - "São Paulo tem 12M habitantes..."
   - "Apresentamos a Multiverse..."
   - "O app funciona assim..."
   - "51% vai para impacto social..."
   - "Nosso guardrails protegem..."
   - "Visão de futuro..."
   - "Obrigado!"

### Passo 3: Parar e Salvar
1. Pare a gravação
2. Adicione legenda se quiser
3. Copie o link
4. Exporte como MP4

## ⚡ Opção Mais Rápida: 1 Minuto

Se você tem pouco tempo:

1. **Abra o app** (index.html)
2. **Abra Loom** ou OBS
3. **Grave a tela** enquanto você fala:
   - "Olá, sou Lucas do projeto Multiverse"
   - "Criamos uma plataforma de economia digital territorial"
   - "Conecta pessoas, comércio local e impacto social"
   - "51% das transações vai para projetos comunitários"
   - "Tem guardrails de segurança e segurança territorial"
   - "O código está no GitHub"
   - "Obrigado!"
4. **Pare a gravação**
5. **Exporte como MP4**

**Tempo total:** 1-2 minutos
